# Sweep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Sweep — SweepCore library + `sweep` CLI + SwiftUI "Gumdrop Platinum" app + SweepAgent — through all six milestones to a usable state.

**Architecture:** SwiftPM package holds `SweepCore` (all deterministic logic, no UI), the `sweep` CLI and `SweepAgent` executables, and tests. The macOS app lives in `App/` as an XcodeGen project that depends on the local package. All external tools run through a `CommandRunner` protocol (direct `Process`, argv, timeouts); all filesystem metadata comes through a `FileSystemProbe` protocol so accounting is testable with fixtures.

**Tech Stack:** Swift 6.3 (language mode 6), SwiftUI + Swift Charts, macOS 14 deployment target, system `libsqlite3`, Security.framework (Keychain), XcodeGen. No third-party Swift packages.

**Spec:** `docs/superpowers/specs/2026-11-07-sweep-design.md`

**Owner override (2026-11-07):** the owner asked to proceed through all milestones without stopping, then run one brutal whole-branch review before declaring the app ready. Execution: Native (implemented in-session), one fresh reviewer at the end.

## Global Constraints

- Deployment target macOS 14.0, arm64 only. Swift language mode 6.
- Bundle IDs: app `dev.algamthe.sweep`, agent `dev.algamthe.sweep.agent`. Dev signing: "Apple Development" identity, team `YOURTEAMID`. Hardened runtime on, App Sandbox off.
- No shell anywhere: executors use `Process` with absolute executable path + argv. Never `/bin/sh -c`, never `zsh`. Timeouts implemented in Swift.
- Physical bytes = `totalFileAllocatedSize`; dataless (`SF_DATALESS` = 0x40000000) files count 0; count each `(dev, ino)` once; never cross `st_dev`.
- Never touch: running containers/volumes, iCloud/Dropbox/OneDrive roots, `~/Library/Keychains`, `~/Library/Mail`, `~/Library/Messages`, dirty git worktrees, user protected paths. Enforced by `SafetyGuard` at execution time.
- Non-cache Tier 3 items → `FileManager.trashItem`; Tier 1 caches and Tier 2 artifacts → hard delete.
- LLM: Anthropic Messages API, model `claude-sonnet-5-5`, key in Keychain; off by default; output schema-validated; unknown item IDs rejected; UI never shows LLM numbers.
- History DB: `~/Library/Application Support/Sweep/history.db`. Logs: `~/Library/Logs/Sweep/`. User rules override: `~/Library/Application Support/Sweep/rules.json`.
- Flavours: Blueberry #2f7fd6 (default), Bondi #0a9bb8, Strawberry #e2445c, Tangerine #ff8a1f, Grape #8a4fc7, Lime #5fbf2f.
- Tests: `swift test --parallel --num-workers 3`.

## Review Focus

1. Paths with spaces, unicode (Arabic file names exist on this Mac) and symlinks → walker must not crash, follow symlinks, or double count. Test in Task 3.
2. A tool binary missing or hanging (Docker daemon down, `uv` absent) → detector yields "tool not installed/unavailable" evidence, scan continues, no hang beyond timeout. Test in Task 2 and Task 8.
3. Permission-denied directories during walk (TCC, root-owned) → counted as inaccessible, never thrown up as scan failure. Test in Task 3.
4. A planned item changed between plan and execute (dev server started, worktree became dirty, path replaced by symlink into protected area) → SafetyGuard re-check blocks it with a reason. Test in Task 12.
5. Malformed / hostile LLM output (extra item IDs, numbers, missing fields, non-JSON prose) → rejected cleanly, app shows "insights unavailable". Test in Task 16.
